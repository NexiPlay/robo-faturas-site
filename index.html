Robô de faturas de energia

Entra no portal da distribuidora com o login do cliente e baixa o PDF da conta de luz.

Entrar

O robô roda no GitHub. Para usar, cole um token do GitHub da sua conta (com acesso ao repositório do robô). Ele fica salvo só neste navegador.

  1. Abra GitHub → novo token (fine-grained).
  2. Resource owner: NexiPlay · Repository access: Only select repositories → robo-faturas.
  3. Permissions → Repository: Actions = Read and write, Contents = Read-only.
  4. Clique em Generate token, copie e cole abaixo.

Nova execução

A máquina do GitHub leva cerca de 1 minuto para começar; a fatura chega em uns 3 minutos e baixa sozinha neste computador.
